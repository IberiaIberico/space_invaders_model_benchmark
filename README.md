# Invaders Bench

🇬🇧 English | [🇪🇸 Español](README.es.md)

A small benchmark that asks different AI models to build the same game, a Space Invaders clone, as a single self-contained HTML file. Each model's output is saved side by side so you can play them and compare quality, speed and cost.

## How it works

1. `invaders_bench.py` sends one fixed prompt (a detailed Space Invaders spec: canvas rendering, shields, UFO, Web Audio sounds, wave progression, etc.) to a model.
2. The HTML in the reply is extracted and saved to `<model>/invaders.html`, together with the raw reply (`response.md`) and run metadata (`meta.json`).
3. `build_index.py` generates `index.html`, a dashboard that links every run, shows its stats and lets you play each game.

## Project layout

```
ai_invaders/
├── invaders_bench.py      # Runs one model and saves the result
├── build_index.py         # Builds the index.html dashboard
├── index.html             # Generated dashboard (open this in a browser)
└── <model-name>/
    ├── invaders.html      # The game generated by the model
    ├── response.md        # Raw model response (local/API runs)
    ├── reasoning.md       # Chain of thought, if the API returned it
    └── meta.json          # Timing, tokens, cost, prompt, settings
```

Some folders (e.g. `sonnet-5.5`, `opus-5.5`, `haiku-5.5`, `fable-5.1`, the `gemini-*` ones) come from agent runs and only contain `invaders.html` and, in some cases, `meta.json`.

## Requirements

- Python 3.10+ (uses `X | None` type syntax). No third-party packages, standard library only.
- To run new benchmarks: [LM Studio](https://lmstudio.ai/) with its local server enabled (default `http://localhost:1234/v1`), or a DeepSeek API key.
- A modern browser to play the games.

## Usage

### View the results

Open `index.html` in a browser. You can filter by name, sort by speed, tokens or size, read the prompts used and click **Play ▶** on any card.

### Run a model through LM Studio

```bash
python invaders_bench.py --list                      # list available models
python invaders_bench.py qwen/qwen3-coder-30b        # run one model
```

### Run through DeepSeek

```bash
python invaders_bench.py deepseek-chat --deepseek-key sk-...
# or take the key from the DEEPSEEK_API_KEY environment variable
python invaders_bench.py deepseek-reasoner --deepseek-key
```

### Useful options

| Option | Description |
| --- | --- |
| `--prompt "..."` / `--prompt-file FILE` | Use a custom prompt instead of the built-in one |
| `--system "..."` | Custom system prompt |
| `--url URL` | API base URL |
| `--folder NAME` | Output folder name (default is derived from the model id) |
| `--out DIR` | Output root directory |
| `--temperature N` | Sampling temperature (default `0.2`) |
| `--max-tokens N` | Max output tokens (default `32000`) |
| `--timeout SECONDS` | Request timeout (default `1800`) |
| `--no-index` | Don't rebuild `index.html` after the run |

### Rebuild the dashboard manually

```bash
python build_index.py
```

Any subfolder that contains an `invaders.html` is picked up automatically. To add an agent run (a model that isn't served through an API), create a folder, drop `invaders.html` in it and optionally a `meta.json`, then rebuild the index.

## The prompt

The default prompt asks for a faithful reproduction of the 1978 arcade game: player cannon with a single shot on screen, aliens that speed up as they die, four destructible shields, a UFO, score, lives, wave progression, pixel-art visuals at a fixed scaled resolution, and Web Audio sound effects, all in one HTML file with no external dependencies. The exact prompt is visible in `invaders_bench.py` and on the dashboard.

## Notes

- Results are non-deterministic. The same model can produce a different game on each run.
- Games are generated by AI models and have not been audited. Open them in a browser as you would any untrusted local HTML.
